# igilarranz.github.io

My personal site: [igilarranz.github.io](https://igilarranz.github.io)

## Files

* `index.html` — main site
* `motionsense.html` — MotionSense-IMU project page
* `404.html` — custom 404
* `resume.pdf` — resume
* `bunny.png` — mascot
* `assets/` — project images and link preview

Everything is plain HTML, CSS, and JavaScript. No build step.

## Deploy

After making changes:

`git add -A && git commit -m "update site" && git push`

GitHub Pages should update automatically after the push.
